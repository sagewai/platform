# Adaptive Intelligence Platform

Dependency-free browser product shell for a deterministic seven-step Adaptive
Intelligence Platform journey. The app uses only local HTML, CSS, JavaScript,
and Node built-ins. All S3, dataset, training, deployment, feedback, and retrain
actions are simulated with non-secret sample values.

## Run

```bash
npm run smoke
```

## Test

```bash
npm run test
```

## Serve Locally

```bash
npm run serve
```

Then open `http://127.0.0.1:4174/`.
